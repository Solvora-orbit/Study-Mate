## ZCode 宿主约定（导出时生成）

> **ZCode 工具对照（本 fork 构建时注入）**：正文里的「宿主文件读取工具」= `Read`（图片查看同样是 `Read`）；写入与编辑 = `Write` / `Edit`；「命令执行」= `Bash`（Windows 下为 Git Bash，PowerShell 语义按上文原文处理）；「委派 / 子 agent」= `Agent` 工具（一个角色一次独立调用，相互独立的角色在同一条消息里并行发起；没有把握时按上文串行执行角色）；「提问工具」= `AskUserQuestion`；「浏览 / 检索」= `WebFetch` 或 `Bash` 里的 `curl`——只允许 `http`/`https`，发起请求前先检查目标主机名，拒绝 `localhost`、环回地址、私有与保留地址；「预览 / 展示页面」= 优先用 ZCode 内置 `visualize` 技能把课件片段渲染成会话内交互视图，需要离线归档时仍按上文 `npx … export` 产出静态副本并给可点击的绝对路径链接。上文提到的「阅读端」在 ZCode 里不存在，一律按本条替代。

- **引擎定位**：本文件位于 `<root>/skills/<技能名>/SKILL.md`；从实际文件路径定位包含 `skills/`、`schemas/`、`templates/`、`docs/` 的插件根目录，记为 `<root>`。插件目录只读，学习数据写入另一个可写工作区。所有相对的 schema、模板与文档路径均相对 `<root>`；参考文档里的旧宿主安装说明不参与本插件启动。
- **加载协议**：正文说“加载某技能”时，用宿主文件读取工具读 `<root>/skills/<技能名>/SKILL.md`；不需要专门的技能调用工具。缺少文件读取能力时说明具体缺项，不声称已加载。所有角色的教学职责与文件归属保持不变。
- **没有引擎脚本**：这个插件只有技能、schema、工作区数据骨架与文档，**不含任何校验器或生成器**（DSH 侧那九个 `studymate_` 原生工具在这里一个都调不到，Python 引擎也已退役）。正文里点名原生工具的地方，导出时已经换成下面那句**本宿主的做法**：按 `<root>/schemas/*.schema.json` 与技能里的格式要求逐项自查，并把自查结论如实报出。缺的能力如实说明，**不要假装调用过工具**，也不要凭空说“已通过校验”。
- **导出**：学生的阅读体验全靠导出。课完（或学生要一份能离线看的）在 shell 里跑 `npx -y @yunmiao/studymate@latest export`——没有参数也能跑，产物落在 `<LEARN_WORKSPACE>/export/`，入口是 `index.html`。它要一份 React（`npm i -g react react-dom`，或设 `STUDYMATE_REACT_DIR` 指过去）。跑不了就如实说明缺什么，不要用别的写法假装导过。
- **工作区**：总控传入的 `<LEARN_WORKSPACE>` 与 `subject_path` 必须是实际绝对路径；新会话按总控的“会话开场”恢复。不要把插件目录、缓存或未知的当前目录当作学习数据目录。角色不另选工作区。
- **工具能力**：只使用宿主实际提供的提问、浏览、文件读写、图片查看、命令执行、委派与预览工具。提问工具不可用时总控用普通对话提问；角色把待问事项交给总控。检索不可用时记录未核验来源与 Gaps，不编造核验结果；图片不可取得时允许空图片库。文件或执行工具不可用时可以继续讨论，但具体生成、持久化与自查必须如实标为未完成。
- **角色执行**：总控阶段的调度动作由总控执行（角色自己能派什么由各自规格决定，规格没写就不派）。有委派工具时按总控规范分工；没有委派工具时由总控按角色规格串行执行，每段读取对应规格，以“准备讲解/核对练习”等工作内容报告进度，完成产物与检查后才切回总控。不得假称启动了子 agent；串行执行仍保留正文→出题→原样搬运的顺序、题目唯一 owner 与档案归属，不能用总控身份随手改角色产物。
- **暂存位置**：产物交接与 DSH 侧同一套约定——角色按最终相对路径写 `<subject_path>/.stage/<角色>-<节点id或slug>/deliver/`，总控核对交付清单后原样搬入、搬完清掉这一轮。不需要留存的中间文件写本会话的 `<STUDYMATE_SCRATCH>`；不同会话、不同角色不共享固定草稿目录，也不要假定任何操作系统的临时目录路径。
- **命令与路径写法**：宿主有命令执行工具时按它的字面值引用与转义规则拼路径（PowerShell 单引号内的单引号写两次）；优先使用工具的参数数组，不能把路径或学生文本拼成未引用的命令。按当前操作系统选择可用的 lab 测试命令（学生跑自己的交付物时用）。角色不建环境，插件缓存内不装依赖。
- **原样搬运**：用宿主文件复制工具完成（Windows 可用 PowerShell 的 `Copy-Item -LiteralPath`）；保留 `deliver/` 中相对路径，不经模型重写题面、答案与长产物。不要依赖别的平台的复制、摘要或打开页面命令。
- **展示与持续保存**：导出产物写盘后用宿主可用的文件预览/浏览器展示，同时给可点击的绝对文件链接；沙箱文件使用宿主支持的下载/附件链接。无预览能力时仍交付文件链接与位置。ChatGPT Work 或其他临时沙箱中，先核实文件是否能跨会话保留；不确定就明确说明，并在结束时交付包含 `export/index.html` 与完整 `.learning/`（含隐藏目录）的可下载归档，下一次从用户提供的归档恢复，不承诺本机目录或沙箱会永久保留。

## Codex 内部规范

本文件是供当前执行者读取的规范；加载它不创建新角色，也不改变调用者身份。总控可以按本规范答疑、维护档案和交互断点；委派角色仍只完成自己的产物，不接管学生对话或总控档案。用户直接选择本规范来继续学习时，先读 `<root>/skills/learning-system/SKILL.md` 并恢复当前学习位置，不从头盘问。

# 题目规范

**字段与词表的唯一出处是代码**：题型的词表、字段与「服务哪一层」见 `lib/core/rules.ts` 的 `QUESTION_KIND_SHAPES`（数据契约 `schemas/question.schema.json`），题面排版与字段写法见 `templates/assets/quiz.js` 顶部注释与 `<root>/docs/规范/课件内容格式.md`——本规范**不抄第二份字段表**，只管**出什么题、怎么要求、什么算过**。

## 一、四层

深度由节点的 `objective` 决定，**不由课型决定**（课型的作用见第四节）。`objective` 写到哪一层，题就出到哪一层。层是"题"的词汇，**不进页面**。

| 层 | 含义 | 通过标准 |
|----|------|---------|
| **读懂** | 能解释为什么，不只给结论 | 说清因果与前提 |
| **改对** | 改一处并**先预测**结果，再跑起来验证 | 预测与实测一致，或能解释差异 |
| **查错** | 定位真实 bug 的根因 | 说出根因 + 修复 + 预防 |
| **造出** | 从零做出可运行的东西 | 交付物能跑通 + 能解释取舍 |

## 二、四种题型

| 题型 | 服务哪一层 | 判分 | 必备字段 |
|------|-----------|------|---------|
| **客观题** | 读懂 | 页内自动判 | `opts`（≥2 项）、`ans`（下标从 0 起）、`why` |
| **预测验证** | 改对、查错 | 先写下预测，再跑起来对照 | `预测`、`比对` |
| **开放题** | 读懂、查错 | 展开参考答案与判分要点，学生自评 | `answer`、`criteria` |
| **交付物** | 造出 | 可运行证据（测试／断言／期望输出） | `交付物`、`证据` |

选题型：**能自动判的优先客观题；要"说清为什么／找根因"的用开放题；要"先预测再验证"的用预测验证；要真做出东西的用交付物。**

判分三轨**全在阅读端**：客观题即时判、主观题学生自评、实操题由 Host 半代跑。**没有任何一轨叫 agent**，三轨都只产生事实与自评，不产生"你会了"的结论。

> **阶段评估已删（ADR-0006）**：不再有跨节点的综合测验，也没有"考考我"那条路——题只服务本节点 `objective` 与它的层。别把综合性测验加回来。

## 三、出题要求

- 贴近生产场景与真实报错，**坚决避免"背诵定义"的「教条主义」**
- 客观题选项尽量等长、同句式（长度泄露答案，检查只 `WARN` 不阻断）
- **只问理解与权衡、不问机械回忆**：对比、因果、预测、取舍、迁移（如"改了这一处会怎样""你项目里哪一处能用上"）。文件名、命令原文、终端输出、报错的行号列号这类东西，要么由 lab 的断言机器验，要么本就没有教学价值；"想不起来"不该成为判定依据
- **开放题必须同时给参考答案与标准**——学生据此自评，缺一不可；答案不唯一时参考答案要给出可接受的替代方案与判断依据，备好常见错误答案，供批改对照
- **预测验证必须让他先写下预测再跑**：没写预测就等于没做这一层；`比对` 写实测是什么、与预测差在哪
- **交付物写成可核验的**（断言／期望输出／清单）；`solutions/` 与任务分开放、做完才对照
- **题量按"学生作答总时长"估，目标 ≤10 分钟**（不设下限也不硬限题数）：实操课与实验课把题量让给练习，概念课可以多问几道；开放题的参考答案要克制，别写成小作文
- 出题前先读节点的 `objective`、学生最近的 misconceptions、目标层级；每题的判分要点写进 `criteria`（必填，学生点开对照时看到的就是它）
- **题面怎么排版不归本规范管**：数学式、换行、围栏、行长这些格式细节以 `templates/assets/quiz.js` 顶部契约与 `<root>/docs/规范/课件内容格式.md` 为准

## 四、三种课型（「课程大纲」的 `kind`）——只管产不产 lab 材料

| `kind` | 是什么 | 产出 |
|--------|--------|------|
| **概念** | 普通课，只讲不落 lab | 课件（讲解 + 轻量练习） |
| **实操** | 普通课，学一点练一点 | 课件 + **自己的小 lab**（当课练习） |
| **实验** | **里程碑验收课**：与普通课同级插在大纲里，验收"学到目前的知识能做出什么" | **实验说明页**（任务书）+ 实操任务（任务本身就是验收） |

**课型不决定题的层级上限**：题出到哪一层看节点 `objective`，把 `kind` 当上限是旧规则，别加回来。深度与课型是两件事。

实验课验收哪些课写在它的 `prerequisites` 里；进度与置位规则见 `record-keeping`。**普通节点没有第三方验收**：推进靠学生自评 + 作答历史 + 机器事实；只有实验课节点走 `evidence-check` 的验收。

## 五、判分要点

- 结论三档：`通过 / 部分通过（列出缺哪条）/ 不通过（列出原因）`，并给"差一步就能过"的具体建议
- **每条结论必须指向一条具体证据**（作答原文、运行结果、交付物）；指不出具体证据按"不通过"处理
- **不得因为"题是我出的"或"学生说懂了"就判过**——说懂了不是证据。证据可信度排序与证据资格见 `evidence-check`

## 六、lab 规范

**载体由总控与学生确定**；本节只管载体定下来后怎么做，讲解角色不碰 lab。交付物的目录布局（任务、答案、`lab/README.md` 各放哪）与各自的维护者见 `<root>/docs/规范/文件归属.md`，别在本规范里另立一套。实验课用同一套要求，另加一份实验说明页——**说明页也是内容格式正文**（语法见 `<root>/docs/规范/课件内容格式.md`），不是 HTML。

不管什么载体，都要做到这五条：**分步引导**（一小步讲解 + 立刻上手，不一次抛完整任务）；**亲手做**（任务留白给学生写，成品只放答案目录，做完才对照）；**可验证**（能自动验的写断言，不能的给自查清单／期望输出）；**即时反馈**（做完立刻能验，不等 agent）；**卡壳先引导**（读错误信息 → 提示 → 线索，不给答案）。教程部分要带结果（其他语言先跑一遍或贴运行结果）；任务写清"要做什么、要点是什么"。

**参考解必须自包含**：学生把答案目录里的文件拷进自己的任务目录后要能直接编译、直接跑——参考解引用的模板、头文件、夹具都得在它自己那份里；要单独入库的模板另存一份进任务目录，并在 `lab/README.md` 写明两者分工。

## 七、题目位置与锚点

**题目位置**是「课件内容文件」里给题留的位置，由讲解角色写成一行指令（写法见 `<root>/docs/规范/课件内容格式.md` 第 4 节）。**锚点文本是两个文件之间的唯一接头**：你按它出题，「练习题库」用同一串文本作键，渲染器按它把题放进页面——**锚点写错或被改写＝报错，不会静默少一道题**。

- **只有 `::: quiz` 的层级是元信息**（读懂／改对／查错／造出是选深度的词汇，锚点才是文件之间的接头），它不落到页面上；`::: practice` 的层级是给学生看的**徽标**（不是题目位置、不写 `empty_reason`），写 `练习`／`上手做` 这类中文阶段名。
- **`empty_reason` 的归属**：某个锚点这轮不该出题，你就对它交回一行 `empty_reason: <理由>`，由总控打进内容文件——**讲解角色不写它**；**锚点有题却写了 `empty_reason:` 也报错**。
- 每处放几道题按第三节的题量估；位的**数量不预设**、按内容定，但每一处都要有交代（收紧到相邻题，或对该锚点交回 `empty_reason`）。
- **对照由工具完成，没有人手抄**：只能按锚点逐字对，对不上一律报错——别按序号对照，两处序号不一致时会**静默错位**。
